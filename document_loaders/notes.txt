Java Backend Development Notes

====================================================
1. What is Java Backend Development?
====================================================

Java Backend Development refers to building the server-side logic of an application using Java. The backend is responsible for handling business logic, database interactions, authentication, APIs, and communication with frontend applications.

Common responsibilities of a Java backend:
- Process client requests
- Perform business logic
- Store and retrieve data
- Authenticate users
- Expose REST APIs
- Connect with external services

Popular frameworks:
- Spring Boot
- Spring MVC
- Spring Security
- Hibernate
- Jakarta EE

====================================================

4. REST API
====================================================

REST stands for Representational State Transfer.

Common HTTP Methods:

GET
Retrieve data.

POST
Create new data.

PUT
Update complete object.

PATCH
Update partial object.

DELETE
Delete resource.

Example:

GET /users

POST /users

PUT /users/5

DELETE /users/5

====================================================
7. Dependency Injection
====================================================

Dependency Injection means Spring creates and manages objects instead of manually creating them.

Constructor Injection is recommended because:
- Easier testing
- Immutable dependencies
- Better design

Example:

public UserService(UserRepository repo){
    this.repo = repo;
}

9. Entity Relationships
====================================================

One-to-One

One-to-Many

Many-to-Many

====================================================
10. DTO
====================================================

DTO means Data Transfer Object.

Purpose:
- Hide entity fields
- Improve security
- Reduce response size

Entity should never be exposed directly.

====================================================
11. ModelMapper
====================================================

ModelMapper converts Entity into DTO and DTO into Entity.

Example:

UserDTO dto =
modelMapper.map(user, UserDTO.class);

24. Best Practices
====================================================

- Keep controllers thin.
- Put business logic in services.
- Use DTOs instead of entities.
- Validate all user input.
- Write unit tests.
- Use constructor injection.
- Handle exceptions globally.
- Follow REST naming conventions.
- Use meaningful variable names.
- Keep methods small and focused.

25. Interview Facts
====================================================

Spring Boot was first released in 2014.

Hibernate is the most popular JPA implementation.

Constructor Injection is preferred over Field Injection.

@RestController = @Controller + @ResponseBody.

JpaRepository extends PagingAndSortingRepository.

Spring Boot uses embedded Tomcat by default.

DTOs improve API security and maintainability.

Kafka enables asynchronous communication between microservices.

JWT is stateless authentication.

ModelMapper automatically maps objects with matching fields.
